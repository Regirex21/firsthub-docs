Un equipo competitivo de FIRST Robotics Competition no depende de una sola persona.

Depende de distintas áreas trabajando juntas con disciplina, organización y comunicación.

En FRC hay espacio para perfiles técnicos, estratégicos, creativos y de liderazgo.

<Aside type="note" title="Idea clave">
No necesitas experiencia previa. Muchos miembros comienzan desde cero.
</Aside>

## Roles en competencia

<Steps>

1. **Driver**  
Controla el robot en match oficial.

2. **Operator**  
Maneja mecanismos y funciones secundarias.

3. **Human Player**  
Interactúa con piezas del juego según reglas.

4. **Coach**  
Coordina estrategia y decisiones rápidas.

5. **Pit Crew**  
Mantiene robot listo entre partidos.

6. **Scouts**  
Recolectan datos para estrategia y selección.

</Steps>

### Qué gana eventos realmente

- Robot confiable  
- Buen drive team  
- Estrategia clara  
- Reparación rápida  
- Buena comunicación  
- Adaptación bajo presión  

<Aside type="caution" title="Verdad competitiva">
Muchos eventos se ganan fuera del campo: pits, scouting y preparación.
</Aside>

</TabItem>

<TabItem label="Negocio">

## Roles de crecimiento

| Área | Qué hace |
|---|---|
| Patrocinios | Conseguir apoyo económico |
| Outreach | Impacto social y comunidad |
| Media | Redes, foto, video y branding |
| Logística | Viajes, tiempos y materiales |
| Finanzas | Presupuesto y compras |

### Por qué importa

Sin estas áreas, incluso un robot fuerte se limita.

- Menos recursos  
- Peor organización  
- Menos visibilidad  
- Menor crecimiento del equipo  

</TabItem>

## Cómo elegir tu rol

| Si te gusta... | Área recomendada |
|---|---|
| Resolver lógica | Programación |
| Construir cosas | Mecánica |
| Orden y detalle | Eléctrica |
| Diseñar | CAD |
| Competir | Drive Team |
| Analizar datos | Scouting |
| Redes sociales | Media |
| Liderar personas | Leadership |

## Cómo progresar dentro del equipo

<Steps>

1. Entrar con actitud humilde  
2. Aprender fundamentos  
3. Ser constante  
4. Volverte confiable  
5. Resolver problemas solo  
6. Enseñar a nuevos miembros  
7. Liderar proyectos  

</Steps>
