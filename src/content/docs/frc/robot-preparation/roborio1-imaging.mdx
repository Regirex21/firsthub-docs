## Instalación de drivers

Los drivers de la roboRIO se instalan automáticamente al instalar las FRC Game Tools. Si es la primera vez que conectas la roboRIO, espera a que Windows complete la instalación.

---

## Abrir la herramienta de Imaging

<img
  src={imagingtool.src}
/>


La herramienta de imaging se puede encontrar dentro de las FRC Game Tools instaladas en tu computadora.

---

## roboRIO Imaging Tool

La herramienta permite:

* Seleccionar la roboRIO conectada
* Configurar el número de equipo
* Actualizar firmware
* Instalar la imagen del sistema

---

## Actualizar firmware

<Aside type="caution" title="Firmware">
Si la roboRIO tiene firmware antiguo, se debe actualizar antes de instalar la imagen.
</Aside>

---

## Instalar la imagen en la roboRIO

<Aside type="caution" title="Importante">
En Windows, asegúrate de ejecutar la herramienta con permisos de administrador.
</Aside>

<Aside type="note" title="Nota">
Este proceso tomará varios minutos y no debe interrumpirse.
</Aside>

<Steps>

1. Abre la herramienta de roboRIO Imaging
2. Selecciona la roboRIO conectada
3. Ingresa el Team Number
4. Selecciona la imagen correcta
5. Presiona **Reformat**
6. Espera a que el proceso termine

</Steps>

## Imaging completo

Cuando el proceso termine:

* La roboRIO se reiniciará
* La imagen quedará instalada
* El Team Number quedará configurado

---

## Solución de problemas

* Verifica conexión USB
* Revisa drivers instalados
* Ejecuta la herramienta como administrador
* Reinicia la roboRIO
* Usa otro cable USB
