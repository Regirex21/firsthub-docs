La FRC Driver Station es la aplicación principal utilizada para comunicarse y controlar el robot durante pruebas y competencias.

:::tip[¿Qué hace Driver Station?]
La Driver Station funciona como intermediario entre la laptop y el robot. Desde aquí puedes habilitar el robot, monitorear el estado del sistema y controlar diferentes modos de operación.
:::

Con ella puedes:

- Conectarte al robot
- Ver el estado de comunicación
- Habilitar y deshabilitar el robot
- Revisar voltaje y errores
- Seleccionar modos de operación

---

## Antes de comenzar

Asegúrate de:

- Tener instalado FRC Game Tools
- Haber configurado el roboRIO
- Estar conectado por Ethernet o USB
- Tener el Team Number correcto

:::note[Consejo]
Conecta primero el roboRIO antes de abrir Driver Station para evitar problemas de detección.
:::

# Indicadores principales

<CardGrid>
  <Card title="Communications">
    Indica si la computadora puede comunicarse con el robot.

    - Verde = conectado  
    - Rojo = sin comunicación
  </Card>

  <Card title="Robot Code">

  </Card>

<CardGrid>
  <Card title="Teleoperated">
    Permite controlar el robot manualmente utilizando joysticks o controles.
  </Card>

  <Card title="Autonomous">

  </Card>

    Deshabilita todos los motores y actuadores del robot.
  </Card>

:::caution[Seguridad]
Nunca habilites el robot si alguien está trabajando físicamente en él.
:::

---

# Habilitar el robot

1. Verifica que:
   - Communications esté en verde
   - Robot Code esté en verde
2. Selecciona el modo deseado
3. Haz clic en `Enable`

El robot debería comenzar a responder inmediatamente.

:::tip[¿Qué sucede al habilitar el robot?]
Cuando habilitas el robot, Driver Station comienza a enviar comandos al roboRIO y permite que el código controle motores y actuadores.
:::
