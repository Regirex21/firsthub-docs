Esta etapa consiste en preparar el robot para que pueda encender, conectarse con la laptop y recibir código correctamente.

Antes de avanzar a programación, el sistema base debe estar estable: roboRIO lista, radio configurada y red funcionando.

<Aside type="note" title="Objetivo de esta fase">
No se busca rendimiento todavía. Primero se busca comunicación confiable y hardware listo para pruebas.
</Aside>

## Ruta recomendada

<Tabs>

<TabItem label="Robot nuevo">

<Steps>

1. Revisar cableado principal  
2. Confirmar batería cargada  
3. Imagen a roboRIO  
4. Configurar radio  
5. Probar conexión en Driver Station  

</Steps>

</TabItem>

<TabItem label="Robot usado">

<Steps>

1. Revisar firmware viejo  
2. Reset de configuraciones previas  
3. Reimaginar roboRIO  
4. Reconfigurar radio  
5. Validar CAN y sensores  

</Steps>

</TabItem>

<TabItem label="Antes de evento">

<Steps>

1. Verificar batería  
2. Confirmar team number  
3. Revisar radio estable  
4. Test rápido de enable  
5. Laptop lista con Driver Station  

</Steps>

</TabItem>

</Tabs>

---

## ¿Qué debes validar al terminar?

- El robot enciende correctamente  
- roboRIO aparece en Driver Station  
- La radio transmite red estable  
- La laptop detecta el robot  
- El código puede desplegarse  
- No hay errores críticos de comunicación  

<Aside type="tip" title="Consejo real">
Si el robot no conecta, normalmente el problema está en red, energía o configuración, no en el código.
</Aside>

## Errores comunes

- Team number incorrecto  
- Imagen desactualizada  
- Radio sin programar  
- Ethernet defectuoso  
- Batería baja  
- Breaker apagado  
- Driver Station mal configurada
