La instalación offline permite preparar todas las herramientas de FRC con anticipación para usarlas en computadoras sin internet o con conexión inestable.

Es especialmente útil para equipos nuevos, talleres, laboratorios escolares y días de competencia.

<Aside type="note" title="Qué lograrás">
Al terminar esta guía tendrás una USB o carpeta local con todo lo necesario para instalar herramientas FRC sin depender de internet.
</Aside>

## Preparación Paso a Paso

<Steps>

1. Desde una computadora con internet, descarga todos los instaladores actuales.
2. Verifica que correspondan a la temporada correcta.
3. Guarda cada archivo en carpetas ordenadas.
4. Renombra archivos si es necesario para identificarlos rápido.
5. Copia todo a una USB o disco externo.
6. Prueba al menos una instalación en otra laptop.

</Steps>

---

## Nombres recomendados de archivos

| Archivo    | Nombre sugerido        |
| ---------- | ---------------------- |
| WPILib     | WPILib-2026.exe        |
| Game Tools | FRC-GameTools-2026.exe |
| LabVIEW    | LabVIEW-FRC-2026.iso   |
| Drivers    | NI-Drivers.exe         |

Estos nombres deben ser coherentes con la temporada y fáciles de identificar rápidamente.
