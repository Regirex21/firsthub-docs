Python es una opción soportada por la comunidad FRC mediante **RobotPy**, permitiendo desarrollar robots con WPILib usando Python.

No es la ruta principal más común, pero puede ser una gran decisión para equipos con experiencia previa o enfoque educativo.

<Aside type="note" title="Qué lograrás">
Al terminar esta guía deberías poder instalar Python, configurar RobotPy, crear un proyecto nuevo y desplegar código al robot.
</Aside>

---

## Antes de empezar

<Aside type="tip" title="Honestidad estratégica">
Si tu equipo busca máxima compatibilidad con tutoriales y recursos FRC, Java sigue siendo la opción más sólida.  
Python conviene cuando existe una razón técnica real para usarlo.
</Aside>

## Instalar Python

<Steps>

1. Descarga Python 3 desde el sitio oficial.
2. Ejecuta el instalador.
3. Marca **Add Python to PATH**.
4. Completa la instalación.
5. Reinicia la terminal.

</Steps>

<Code
code={`python --version`}
lang="bash"
title="Verificar instalación"
/>

```text
[IMAGEN PLACEHOLDER: Instalador con Add Python to PATH seleccionado]
```

---

## Instalar RobotPy

<Code
code={`pip install robotpy`}
lang="bash"
title="Instalar RobotPy"
/>

<Code
code={`python -m robotpy --help`}
lang="bash"
title="Verificar instalación de RobotPy"
/>

<Aside type="note" title="Importante">
Muchos errores vienen de múltiples versiones de Python instaladas. Usa siempre la misma versión.
</Aside>

---

## Crear Proyecto Nuevo

<Steps>

1. Abre terminal en la carpeta deseada.
2. Ejecuta el comando de inicialización.
3. Abre la carpeta en VS Code.
4. Empieza a programar.

</Steps>

<Code
code={`python -m robotpy init`}
lang="bash"
title="Crear proyecto RobotPy"
/>

```text
[IMAGEN PLACEHOLDER: Carpeta de proyecto RobotPy creada]
```

## Problemas Comunes

<Tabs>

<TabItem label="python no reconocido">

Python no está agregado al PATH. Reinstala activando esa opción.

</TabItem>

<TabItem label="pip falla">

<Code
code={`python -m pip install --upgrade pip`}
lang="bash"
title="Actualizar pip"
/>

</TabItem>

<TabItem label="Deploy no conecta">

Revisa red, IP del robot y Driver Station.

</TabItem>

<TabItem label="Múltiples versiones">

Usa `py -3` o la ruta explícita correcta.

</TabItem>

</Tabs>
