## Ruta Recomendada

<Steps>

1. Confirmar que todas las herramientas abren correctamente.  
2. Crear primer proyecto de robot.  
3. Conectar roboRIO por USB o red.  
4. Compilar código sin errores.  
5. Hacer primer deploy.  
6. Probar movimiento básico.  

</Steps>
