Esta sección reúne todo lo necesario para preparar una computadora para FIRST Robotics Competition.

Aquí encontrarás el orden recomendado para instalar software, resolver problemas comunes y dejar una laptop lista para temporada.

<Aside type="note" title="Objetivo">
Al terminar esta sección deberías poder programar, conectar controles, usar Driver Station y crear proyectos con WPILib.
</Aside>

## Orden recomendado para equipos nuevos

<Steps>

1. Preparar la computadora  
2. Instalar FRC Game Tools  
3. Instalar WPILib  
4. Instalar librerías de hardware (REV / CTRE)  
5. Verificar VS Code y Driver Station  
6. Crear primer proyecto  
7. Probar deploy o simulación

</Steps>

---

## Requisitos recomendados

| Elemento | Recomendado |
|---|---|
| Sistema operativo | Windows 10 / 11 |
| RAM | 8 GB mínimo |
| Espacio libre | 15 GB+ |
| Internet | Estable |
| USB disponibles | Sí |

<Aside type="tip" title="Consejo">
Si el equipo tiene varias laptops, prepara una memoria USB con todos los instaladores.
</Aside>
