LabVIEW es uno de los entornos oficiales soportados en FIRST Robotics Competition para desarrollar robots FRC mediante programación gráfica.

Es ampliamente usado en educación e industria, y ofrece integración sólida con hardware de National Instruments.

<Aside type="note" title="Qué lograrás">
Al terminar esta guía deberías poder abrir LabVIEW, crear un proyecto FRC y preparar deploy hacia un roboRIO.
</Aside>

## ¿Quién debería usar LabVIEW?

## Antes de instalar

* Windows 10 u 11 actualizado
* Internet estable
* Espacio libre suficiente
* Permisos de administrador
* Cerrar programas de NI abiertos
* Tener FRC Game Tools instalado (recomendado)

<Badge text="Solo Windows" />

---

## Instalación Paso a Paso

<Steps>

1. Descarga el instalador oficial correspondiente a la temporada actual.
2. Ejecuta el archivo como administrador.
3. Selecciona instalación completa recomendada.
4. Espera a que terminen todos los paquetes.
5. Reinicia la computadora al finalizar.
6. Abre LabVIEW desde el menú inicio.

</Steps>

---

## Verificar Instalación

* LabVIEW abre correctamente
* Existe plantilla **FRC roboRIO Robot Project**
* Detecta soporte para roboRIO
* Sin errores de runtime o licencia

## Crear Proyecto FRC

<Steps>

1. Abrir LabVIEW.
2. Seleccionar **FRC roboRIO Robot Project**.
3. Ingresar team number.
4. Elegir plantilla base.
5. Guardar proyecto.

</Steps>

---

## Deploy al roboRIO

<Aside type="note" title="Flujo habitual">
Build Specifications → FRC Robot Boot-Up Deployment → Build → Run as Startup
</Aside>

---

## Problemas Comunes

<Tabs>

<TabItem label="No aparece plantilla FRC">

Reinstala componentes FRC correctos o usa la versión oficial de temporada.

</TabItem>

<TabItem label="No detecta roboRIO">

Revisa USB, Ethernet, Driver Station e imagen del roboRIO.

</TabItem>

<TabItem label="Instalación lenta">

Es normal. Los paquetes de NI suelen ser pesados.

</TabItem>

<TabItem label="Errores extraños">

Haz instalación limpia y reinicia el equipo.

</TabItem>

</Tabs>
