WPILib es el entorno principal usado en FIRST Robotics Competition para programar robots en Java y C++.

Incluye herramientas oficiales, librerías, simulación y una versión de VS Code preparada para FRC.

<Aside type="note" title="Qué lograrás">
Al terminar esta guía deberías poder abrir WPILib VS Code, crear proyectos nuevos y compilar código sin errores.
</Aside>

## Antes de instalar

- Windows actualizado
- Internet estable
- Espacio libre suficiente
- Permisos de administrador
- Cerrar IDEs abiertos

<Aside type="tip" title="Recomendación">
Si es laptop del equipo, crea una cuenta exclusiva para robótica.
</Aside>

## Instalación paso a paso

<Steps>

1. Descarga el instalador de WPILib correspondiente a tu sistema operativo.  
2. Ejecuta el archivo como administrador.  
3. Selecciona la versión actual recomendada.  
4. Elige instalación para usuario actual (normalmente suficiente).  
5. Espera a que termine la instalación.  
6. Reinicia la computadora si se solicita.  
7. Busca **WPILib VS Code** en el menú inicio.

</Steps>
