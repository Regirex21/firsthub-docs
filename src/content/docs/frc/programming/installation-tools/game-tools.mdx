FRC Game Tools es el paquete oficial que instala las herramientas esenciales para participar en la temporada de FIRST Robotics Competition en Windows.

Incluye componentes necesarios para operar robots, conectarse al campo, actualizar firmware y utilizar el entorno oficial de competencia.

---

## ¿Qué incluye FRC Game Tools?

Dependiendo de la versión de temporada, normalmente instala:

- Driver Station
- FRC Radio Configuration Utility
- NI Update Suite
- LabVIEW Runtime Components
- Herramientas USB / CAN necesarias
- Utilidades oficiales de comunicación

---

## Requisitos Previos

Antes de instalar:

- Windows 10 u 11 (recomendado)
- Cuenta con permisos de administrador
- Conexión a internet
- Haber cerrado programas de NI abiertos
- Antivirus sin bloquear instaladores

> Esta herramienta es solo para Windows.

---

## ¿Quién necesita instalarlo?

### Obligatorio para:

- Driver Station laptops
- Computadoras de programación en pits
- PCs de prueba del robot
- Equipos que usarán Driver Station
---

## Descarga Oficial

Descarga siempre desde:

- Sitio oficial de WPILib
- Página oficial de FIRST Robotics Competition
- Repositorios enlazados por WPILib

> Nunca uses versiones viejas encontradas en terceros.

## Actualización Anual

Cada temporada cambia la versión.

Eso significa:

- Instalar nueva versión cada año
- No depender de versiones anteriores
- Revisar compatibilidad con WPILib actual

---

## Problemas Comunes

### Instalador no abre

Solución:

- Ejecutar como administrador
- Desactivar antivirus temporalmente
- Redescargar archivo

### Driver Station no detecta robot

Revisar:

- IP correcta
- Ethernet
- Firewall
- Radio configurada

### Error de NI components

Reinstalar Game Tools completo.
