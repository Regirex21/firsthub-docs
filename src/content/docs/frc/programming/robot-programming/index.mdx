En esta sección aprenderás a crear y ejecutar tu primer programa para un robot FRC utilizando WPILib.

Aquí encontrarás los pasos básicos para:

- Crear un proyecto de robot
- Configurar el drivetrain de prueba
- Desplegar código al roboRIO
- Ejecutar y probar el robot
- Verificar comunicación con Driver Station

:::tip[Recomendación]
Si es tu primera vez en FRC, utiliza Java como lenguaje principal. Es el lenguaje más utilizado y tiene mayor cantidad de recursos y ejemplos.
:::

---
