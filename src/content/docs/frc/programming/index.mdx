El área de programación desarrolla el software que permite controlar el robot durante prácticas, pruebas y competencia.

En FRC, el código conecta hardware y estrategia: manejo, mecanismos, sensores, dashboards, autónomos y diagnóstico.

<Aside type="note" title="Empieza aquí">
Si eres nuevo, comienza por Instalación y Herramientas. Puedes avanzar sin dominar programación al inicio, pero para crecer necesitarás practicar un lenguaje.
</Aside>

## ¿Nuevo en programación?

Puedes empezar aunque no sepas programar. Muchos miembros comienzan aprendiendo las cosas más básicas, y pequeñas tareas.
Apoyarse en miembros con más experiencia es clave, y no hay preguntas tontas.

<Aside type="tip" title="Recomendación">
Si tu equipo no tiene un estándar definido, Java es la mejor opción para comenzar en FRC.
</Aside>

## Buenas prácticas

- Código entendible  
- Cambios pequeños y probados  
- Nombres claros  
- Uso constante de Git  
- Respaldos frecuentes  
- Documentar decisiones  
- Probar antes del evento  

<Aside type="tip" title="Consejo">
Es mejor un sistema simple y confiable que uno complejo e inestable.
</Aside>
