El área de programación se encarga de desarrollar el software que permite operar el robot durante prácticas, pruebas y competencia.

En FRC, el código controla sistemas de manejo, mecanismos, sensores, rutinas autónomas y herramientas de diagnóstico.

<Aside type="note" title="Importante">
Un robot competitivo necesita buena mecánica, buena estrategia y software confiable.
</Aside>

---

## Lo que normalmente se trabaja en temporada

- Base de manejo  
- Integración con hardware nuevo  
- Ajuste de controles para drivers  
- Código de mecanismos  
- Rutinas autónomas  
- Pruebas en campo  
- Corrección de fallas rápidas  
- Versionado de cambios  

---

## Buenas prácticas

- Código ordenado y entendible  
- Nombres claros en variables y clases  
- Cambios pequeños y probados  
- Uso de Git  
- Respaldos frecuentes  
- Documentar decisiones importantes  
- Probar antes del evento  

<Aside type="tip" title="Recomendación">
Es mejor un sistema simple y estable que uno complejo e inconsistente.
</Aside>

---

## Errores comunes

- Programar sin probar físicamente  
- Cambiar muchas cosas antes de competir  
- Depender de una sola persona  
- No usar control de versiones  
- Código duplicado y desordenado  
- No registrar errores del robot
