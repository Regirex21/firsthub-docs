## Propósito

Reconoce un sistema de control innovador, o una aplicación innovadora de componentes de control — eléctricos, mecánicos o de software — usados para lograr una función del robot que se salga de lo común.

<Aside type="caution" title="Cambia por temporada">
El criterio completo de evaluación vive en la fuente oficial, no aquí — puede variar cada año.
</Aside>
