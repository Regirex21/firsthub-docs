FIRST agrupa estos premios como **"Standalone Awards"** — están fuera de las tres categorías anteriores (Máquina/Creatividad/Innovación, Atributos de Equipo, Por Postulación).

<Aside type="note" title="Fuente">
Contenido traducido de <a href="https://www.firstinspires.org/resources/library/frc/awards">Awards</a> (firstinspires.org).
</Aside>

<Aside type="caution" title="Cambia por temporada">
Criterios de evaluación vigentes pueden variar cada año — confirma el detalle en la fuente oficial de cada premio.
</Aside>

<Aside type="note" title="Founder's Award no incluido">
FIRST también tiene un "Founder's Award" standalone, pero no encontramos una descripción oficial confiable de su propósito para traducir con confianza — queda fuera de esta sección hasta poder verificarlo. Ver <code>PENDIENTES.md</code>.
</Aside>
