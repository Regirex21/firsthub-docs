## Propósito

Celebra a un equipo que usa sensores y software para ampliar la funcionalidad del robot durante el juego — el énfasis está en cómo el software y la retroalimentación de sensores hacen que el robot haga más, o lo haga mejor, no solo en que el código "funcione".

<Aside type="caution" title="No confundir con el Control Award submission">
Este premio evalúa el sistema de control del robot en general. No debe confundirse con el "Control Award submission", un documento específico de judging con su propio formato — ese es un artefacto de evaluación distinto a lo que describe esta página.
</Aside>

<Aside type="caution" title="Cambia por temporada">
El criterio completo de evaluación vive en la fuente oficial, no aquí — puede variar cada año.
</Aside>
