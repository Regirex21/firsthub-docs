En esta sección aprenderás a crear y ejecutar tu primer OpMode para un robot de FTC, usando Java o Blocks.

Aquí encontrarás los pasos básicos para:

- Crear un OpMode de drivetrain
- Configurar los motores en el Control Hub
- Leer el gamepad para controlar el robot
- Compilar o guardar tu OpMode
- Ejecutarlo y probarlo desde Driver Station

<Aside type="tip" title="Recomendación">
Si tu equipo ya decidió su ruta en Instalación y Herramientas, ve directo a la guía de Java o Blocks correspondiente. Si aún no lo decidieron, ambas guías construyen exactamente el mismo robot, así que puedes leer las dos antes de elegir.
</Aside>

---

## Antes de comenzar

Asegúrate de haber completado:

- Instalación y herramientas (Android Studio si usarás Java, o acceso a Blocks/OnBot Java)
- Configuración del Control Hub
- Instalación de la app Driver Station
- Conexión básica entre Driver Station y el Control Hub

## ¿Qué aprenderás después?

Más adelante podrás continuar con temas como:

- Autónomo básico con temporizadores
- Sensores: encoders, IMU, sensores de color y distancia
- Visión: detección de AprilTags y TensorFlow
- Road Runner para trayectorias
- FTC Dashboard para tuning en tiempo real

<Aside type="note" title="Importante">
Esta sección está enfocada en el primer drivetrain funcional. Los temas avanzados de autónomo, sensores y visión tendrán secciones dedicadas más adelante.
</Aside>
